# Hryvnia Economy (money_mine)

Fabric-мод для **Minecraft 26.2**, який повністю замінює смарагдову торгівлю селян на грошову економіку з гривнею ₴.

## Можливості

- **Готівка** — купюри-предмети: 1, 2, 5, 10, 20, 50, 100, 200, 500, 1000, 2000 ₴. Решта видається автоматично найменшою кількістю купюр.
- **Банківська картка** — фізичний предмет. Наведи курсор — побачиш номер картки, власника і свій баланс. Унікальний 16-значний номер на сервері, максимум одна картка на гравця.
- **Банкіри** — селяни нової професії. З'являються **тільки природно** (шанс при появі селянина у селі, за замовчуванням 15%). Їх неможливо створити робочим блоком чи розведенням — тому вони в дефіциті. У банкіра: депозит готівки, зняття, видача картки, **перекази за номером картки іншим гравцям**, здача смарагдів як брухту (5 ₴/шт).
- **Робота** — правий клік по селянину з професією відкриває вікно: кнопка «Найнятись», 5 слотів для здачі товару, оплата **готівкою або карткою** на вибір. Що приймає селянин — залежить від професії (м'ясник — м'ясо, фермер — врожай, рибалка — риба…). Ставки видно у тултіпі кнопки «Здати товар».
- **Одна робота одночасно.** Звільнитися можна кнопкою у того ж селянина (без команд).
- **Магазин** — у кожного роботодавця свій асортимент (12 професій, ~100 товарів загалом), оплата готівкою або карткою.
- **Смарагди тепер useless**: ванільне вікно торгівлі не відкривається ні у селян, ні у мандрівного торговця. Єдине застосування смарагда — брухт у банкіра.
- Баланси/роботи/картки зберігаються у `<world>/hryvnia_economy.json` (автозбереження кожні 5 хв і при зупинці сервера).

## Збірка

Потрібні **JDK 25** та інтернет (Gradle сам завантажить Minecraft 26.2, Loom `1.17-SNAPSHOT`, Fabric API `0.155.2+26.2`).

```bash
./gradlew build
# готовий мод: build/libs/hryvnia-0.1.0.jar
```

Запуск клієнта для тестів: `./gradlew runClient`.

> **Важливо:** мод написаний під зовсім свіжі мапінги 26.2 без можливості зібрати його в середовищі, де він створювався (там заблоковані сервери Mojang/Fabric і немає JDK 25). Серверна частина (`src/main`) вже проходить компіляцію; клієнтські екрани (`src/client`) компілюються окремою таскою `compileClientJava`. **Якщо `./gradlew build` видасть помилки — надішли повний лог, я виправлю.**

## Ринок і банк: реалізм

- **Щоденні ціни.** У магазинах ціна — діапазон (`priceMin`..`priceMax`). Щодня (реальна доба) кожен селянин «котирує» свою ціну; розподіл експонентний — що дешевша ціна, то рідше вона випадає (`priceBias` регулює перекіс). У різних селян ціни різні — вигідно порівнювати.
- **Не всі беруть картку.** ~90% працюючих селян приймають картку (`cardAcceptancePercent`); решта «оминає податки» — тільки готівка (кнопка оплати показує «Тільки готівка»).
- **Картка коштує 10 000 ₴** готівкою (`cardPrice`), ліміт зберігання — **100 000 ₴** (`cardBalanceLimit`). Якщо зарплата на картку не влазить — видається готівкою.
- **Ліміт переказів: 40 000 ₴ на день одному гравцеві** (`transferDailyLimit`), рахується за реальною добою і прив'язаний до гравця, а не картки.
- **Комісії:** зняття готівки — 1% (`withdrawFeePercent`), поповнення — 0% (`depositFeePercent`), переказ — 2% (`transferFeePercent`, платить відправник зверху). Округлення вгору.

## Конфіг

`config/hryvnia.json` створюється при першому запуску:

```json
{
  "bankerSpawnChance": 0.15,
  "emeraldScrapValue": 5,
  "cardAcceptancePercent": 90,
  "priceBias": 2.0,
  "cardPrice": 10000,
  "cardBalanceLimit": 100000,
  "transferDailyLimit": 40000,
  "withdrawFeePercent": 1.0,
  "depositFeePercent": 0.0,
  "transferFeePercent": 2.0,
  "professions": {
    "minecraft:butcher": {
      "jobRates": { "minecraft:beef": 3 },
      "shop": [ { "item": "minecraft:cooked_beef", "count": 1, "price": 12, "priceMin": 10, "priceMax": 15 } ]
    }
  }
}
```

- `bankerSpawnChance` — шанс, що новий безробітний селянин стане банкіром
- `jobRates` — ₴ за 1 шт. зданого товару (фіксовані)
- `shop` — асортимент; без `priceMin`/`priceMax` ціна фіксована (`price`); ліміти/комісії `0` — вимкнені

Після редагування: `/hryvnia reload` (потрібен рівень оператора 2).

## Команди (тільки для адмінів)

- `/hryvnia reload` — перечитати конфіг
- `/hryvnia banker` — перетворити найближчого дорослого селянина (до 8 блоків) на банкіра: для тестів або щоб поставити банкіра у село вручну
- `/hryvnia balance <гравець>` — показати баланс
- `/hryvnia balance <гравець> set|add <сума>` — змінити баланс

## Як упізнати банкіра

- Наведи приціл — над ним ім'я **«Банкір»**
- Оверлей скіна: темно-синій костюм із золотою краваткою (`textures/entity/villager/profession/banker.png`)
- Правий клік відкриває вікно банку, а не роботодавця

## Як це працює всередині

- Правий клік по селянину перехоплюється (`UseEntityCallback`) — ванільні трейди недосяжні.
- Банкіром стає безробітний дорослий селянин у момент першої появи у світі (природний спавн/генерація села). Розведені селяни позначаються тегом і банкірами не стають ніколи.
- Професія `hryvnia:banker` зареєстрована без робочого POI, тому гравець не може «зробити» банкіра.
- Баланс живе на сервері; клієнту надсилається пакетом для тултіпа картки та екрана банку.
